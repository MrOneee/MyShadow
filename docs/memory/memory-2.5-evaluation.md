## 改动及证据

2.3新增独立原话证据，2.4引入权限过滤后的模型语义选择。2.5继续使用同一批2.3记忆库的副本，未重新提取，主要修复“证据已返回但没有被用于回答”的问题，并减少候选截断：

- 语义目录中的原话窗口从120增加到400字符，目录预算48000→96000字符，仍最多240条；优先选择具体、互补的原话，减少重复概括。
- 回答规则明确允许由已有证据去重计数、比较先后、计算相对日期与时长。partial不代表已返回事实无效，画像冲突不自动否定所有历史事件。
- 修正“没有回忆工具就说明没有记录”的过宽表述：应先使用已经给出的上下文，仅工具和资料都不能提供所需信息时说明缺失。
- 最终回忆仍最多12条、约6500字符，主动回忆仍最多两次。成员/会话隔离、共享权限、原话角色、来源删除与调用期间撤回检查保持不变。

2.5相对2.4，LME有7题转对、无转错；LoCoMo有6题转对、2题转错，其中可回答净增5题、拒答少对1题。LME转对包括家传物品计数、乐器计数、阅读先后和日期间隔；这些不是新增的标准答案规则，而是原话证据的组合使用。两处读取改动同时进行，不能把全部收益单独归因于提示或目录窗口之一。独立重复的逐题波动已保留，不能把temperature=0等同于完全确定。

## 验证与版本更替

101项相关测试通过，涵盖来源/成员隔离、伪造序号、删除/停记/到期清理期间的读取撤回、预算、状态更新、生产上下文接线。首次测试有一个既有多日关系测试在23点后跨日失败；把测试时间固定在中午后全套通过，未修改关系计分；失败日志一并保留。

实际DSH链路两项检查通过：自动上下文正确读取最新累计值7；主动回忆工具正确返回10月19日的活动日期和6号圆头画笔。使用隔离依赖及合成资料，未导入完整Bot/微信，不冒充端到端验证。DSH调用实际采用语义选择，结果与环境记录可查。

52个复用库原件均未改。2.4→2.5隔离升级验证中，除版本标记外所有表内容保持一致，重复初始化幂等，原库不变。旧库升级不会自动重新提取历史；2.3以前没有保存的独立证据不会凭升级产生。部署需成套代码与备份，回退保持删除/停记效力，详见[版本记录](MEMORY_VERSIONS.md)。当前仅更新工作区，没有部署或Git提交。

上述都是读取评测成本，另有2.3首次完整提取9,860,071 token。DSH补充检查另用12,308 token（提取4,942、选择1,405、DSH回答5,961）。更大目录以额外模型输入换取细节，不能宣称同成本提升；2.5首次LME/LoCoMo读取中位延迟约1.55/2.44秒。none/oracle条件沿用历史参考，未同期重跑。

目前主要剩余问题是长列表遗漏、早期细节在提取或候选阶段丢失、相近事件混淆及时间/类别推理错误。例如把物理治疗也算成医生预约、漏列旅行国家或读过的书、将不同日期的同类活动混淆。部分公开题与产品敏感信息保存策略不一致，不能为分数放宽过滤。有限回归集经过多轮查看，过线不能证明开放场景已达到相同比例；新问题确认和后续全新对话验证需单独看。
