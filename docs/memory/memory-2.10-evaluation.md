# 记忆2.10.0评测：有原文支撑的候选值标注

本轮已完成，按事前冻结协议达到目标：首次固定回归LME31/36（86.11%）、LoCoMo60/92（65.22%），独立重复32/36（88.89%）、58/92（63.04%）；封存新68题20/24（83.33%）、22/32（68.75%）。三个阶段均达到LME≥70%、LoCoMo≥60%的样本正确率门槛，completion-audit.json全部通过。

2.9固定回归过线但新题15/24、17/32未过线的记录保留。本轮依据旧回归与候选审计优化，没有查看封存新题问答调参，也没有重新抽题择优。本结论不表示全量基准或总体正确率保证；未部署生产。

## 方案与变更

[事前方案](memory-2.10-plan.md)先于实现保存；新68题种子20261030，排除此前500题，已封存。选择器在同一次调用中标注原文中的候选名称、动作、数值或日期，宿主逐字核验后以focus_spans返回，同时保留完整候选上下文、角色、状态与来源。无效标注只丢弃标注并记录focus_filtered；无效主引文仍按已有规则词面回退，两者分别统计。

每记录至多6项、每项100字符、全次600字符；不生成答案、补充关系或改写原文。标注计入既有16条/9000字符预算，可能挤掉后部上下文。目录240条/160000字符、选择输出2400 token、模型调用次数上限及模型、评分口径不变。同源包含去重合并互补标注，不合并不同人物、角色、时点或画像状态。

核验边界：对于来源原话/经历窗口，标注对应原始话语；对于画像，核验的是已授权的存储正文或其来源引文，画像正文可能是写入时生成的概括，不能把其中的中文概括标注称为用户逐字原话。kind、basis和完整来源仍保留，候选值不是新事实或最终答案。

只读复用2.9的52库副本，历史写入内容来自2.6；没有复制旧回答/评分。deepseek-flash、temperature=0、thinking关闭，题集及裁判冻结。

## 首次结果与成本

278次自动选择中266次正常、12次只过滤无效focus标注；没有非法主引文导致的词面回退。主动回忆1次，其中两位说话者分别调用选择器，共2次选择，均正常；对应额外1次回答请求。601次请求共5,142,966 token：选择4,330,450、回答787,546、评分24,970。用量不含2.6的14,878,507写入token。首次比2.9首次4,997,466 token增加约2.91%；调用上限不变不代表实际成本不变。首次LME/LoCoMo读取中位延迟2.25/2.94秒、回答阶段2.98/3.80秒，尾部延迟见analysis.json。

首次相对2.9，LME2题转对、2题转错；LoCoMo含拒答3题转对、5题转错。厨房设备先后及集市间隔恢复，睡觉时间退为拒答；阅读顺序题列出了两个日期，却把较晚一本当成先读，表明突出候选值并未解决比较推理。海边交流、加拿大及州名推断也出现退步。配对区间跨0，不能宣称稳定改善。

人工复查还发现：集市间隔答“3周2天”所列日期实际相差22天，参考答案为3周，冻结裁判仍判对；LoCoMo 6:65与2.9答案文字完全相同，但语义裁判由对转错。两项都保留官方流程原分，另记录偏差，不能把分数当成精确推理质量或完全确定的真值。

返回标注逐条核验统计见focus-audit.json，包括画像/原话/经历分布、单次最大字符数及违规清单；三阶段分别核验2,309、2,307、958个片段，无超预算或找不到宿主正文/来源引文的标注；单次最大字符数598、600、590。这只证明标注有来源，不证明选择或最终答案正确。

## 独立重复与稳定性

第二次601次请求、5,143,947 token：选择4,331,149、回答788,170、评分24,628。自动选择266次正常、10次仅过滤focus、2次非法主响应词面回退；主动回忆一次含两位说话者选择，均正常。没有API或评分错误；词面回退不冒充API错误。相对首次LME1题转对、0题转错；LoCoMo2题转对、4题转错。两次自动选择共出现2次主响应词面回退，具体为旧回归LoCoMo 1:31和5:3；调用日志不记录完整选择原始响应，不能进一步断言具体违反的是哪个字段。

LME42题中20题上下文完全相同、23题答案完全相同、41题评分一致；LoCoMo118题分别37、65、112。新增可选标注本身也会造成上下文字符串变化，不能把全部变化都归因为召回变化。两次未观察到相同答案文字却评分不同，但跨版本已有该现象，仍不能排除裁判噪声。见repeat-stability.json。

## 评测边界

固定160题已用于多轮开发，不能代表全量基准。新LoCoMo题来自原10段对话池，不是新对话泛化。重放仅含文字，不包含图片理解；来源重建只是乐观诊断，不是官方Recall@K。回答与语义裁判同模型，存在生成与评分波动。样本达标不等于总体正确率置信下界达标。

本轮使用最后4道未用LME单轮偏好题和4道拒答题；后续若继续迭代，必须事前说明无法沿用完全相同的平衡新题抽样，不能把旧题重新称为新题。
