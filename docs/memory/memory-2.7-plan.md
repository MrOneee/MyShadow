已知回归的两次差异显示两类问题：一部分候选变化导致列表遗漏，另一部分在完全相同证据上仍错算相对时间或漏读相关项。目录只返回序号，回答仍需从长片段中重新找细节；2.6角色窗口虽有basis元数据，但目录未提供该字段，也削弱了选择器区分本人陈述和助手建议的能力。

本轮只改读取，复用2.6记忆库的SQLite副本，不混入重新提取波动。单次选择模型改为返回记录序号和精确原话片段，要求覆盖所问各对象、动作、限定与时间，不生成答案、推测或改写。宿主校验每个片段必须是该授权记录正文或已授权原话引文的连续子串，角色、来源时间、状态由宿主原记录提供。保留同一数据库调用前后撤回检查，不增加第二次外部调用，防止在撤回后继续发送旧资料。

仅空白格式不同的摘录可以定位回实际连续原文，最终仍返回原文中的空格/换行，不接受新增或改写的词句/标点。同一记录重复输出时合并至多3个已核验片段，不让后一个片段覆盖前一个。

目录显式提供basis；原文窗口上限600字符，目录总上限由96000增至160000字符，仍最多240条。输出token上限600→2400以容纳原话片段；最终仍最多12项、约6500字符。非法片段不能进入结果；格式/序号错误保留可诊断的有界回退。兼容合法序号列表，但不允许模型生成文本替代实际记录。

自动上下文中的画像附上状态与同会话的原话时间，避免没有日期的最新概况干扰历史问题。核查现有_visible已经排除冲突/过期观察，保留该行为，不把它们重新加入自动概况；相关检索仍保留其明确状态。共享画像不额外暴露其他会话的时间或来源。读取规则要求按问题维度完整汇总，允许用常识解释明确地点、术语及日期，不用常识编造个人经历或敏感属性；当前事实、历史事实、计划与助手建议继续区分。

对于有单条原话时间锚点的事件/角色窗口，增加确定性的日历释义：如昨天、这个月、上个月、若干天/周前，使用该条asserted_at换算，保留原话。仅释义字面时间表达，不推断事件发生，不处理有歧义的“上周末/上周四”，不使用提问日替代原话日，也不为混合多来源的画像套用同一锚点。释义随同一个6500字符预算计算；增加月末、跨年、数字时长、无锚点及不支持表达测试。
