## 实际部署内容

七个记忆核心文件与2.10评测快照字节一致：member_memory、member_memory_policy、member_profiles、member_retrieval、member_evidence、member_selector、member_calendar。生产版本标记仍为2.10.0，本次另记录生产接线修订，不覆盖已冻结的离线评测快照或分数。

线上Bot比本地评测工作区含有更新的私聊合并、文件处理、表达方式、模型可见性等实现；没有用本地Bot整文件覆盖。以服务器现有Bot为基础，只合并当前问题传入记忆、reader_factory绑定，以及队列使用统一USER_LIMIT/ASSISTANT_LIMIT三项行为（另加常量导入）。实际部署文件、前后哈希和补丁见[部署资料](../../benchmarks/memory-deployment-2.10-2026-10-23/)。

联调发现：原Bot的memory_outbox仍在800字符截断已确认回复，虽然MemoryService已支持4000。现在队列与服务统一使用用户1000、助手4000字符上限，先检查完整输入的敏感性再截断；Windows本地同步修复此入口，增加三项队列回归。只有已确认交付进入该路径，未恢复旧回复已经丢失的尾部。这是生产集成修复，不是另一次基准测分。

背景知识模块保留服务器版本的owner_only访问控制及其排序；social_memory、AIClient、agent_runtime/ai也保留服务器版本。旧记忆模块中的JEV memory_reviews/memory_rerank接入随记忆核心替换为2.10提取、状态更新及有界证据选择流程；其他模块的JEV接入未修改。未更改线上AI或Bot配置。
