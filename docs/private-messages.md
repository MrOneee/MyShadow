# 私聊回复

`bot.json` 中的 `private_messages.enabled` 控制好友私聊回复；`enabled_since` 是启用时间戳，避免首次启用后补回此前的消息。关闭再开启时如需跳过停用期间的消息，应同时更新启用时间。

收到好友的新文字、引用正文或图片时，不需要 @ 即进入现有回复队列。公众号、系统账号、文件传输助手、已删除或拉黑联系人、机器人自己的消息不会触发。语音和视频目前没有新增识别或触发能力。

私聊使用默认“影”人设。联系人 ID 作为会话键，与群 ID 分开保存历史、摘要、社会记忆和 DSH 会话。不会自动继承所在群的蒋丞背景，也不能读取其他会话的聊天记录。历史查询、搜索、天气、图片与表情工具复用现有实现；定时任务仍需真实管理员身份，目标只能是当前私聊。群活动主持不在本次私聊功能范围内。

每位联系人串行处理，不同联系人共用原有有界工作队列；桌面发送仍全局串行。发送前检查联系人有效性、备注或昵称唯一性，定位搜索结果的联系人区域，再校验窗口标题。重名、改名、删除、输入框已有草稿时停止发送；送达确认依旧检查目标会话数据库，不确定时不自动重发。

验证涵盖好友筛选、文字/引用/图片触发、自身消息和旧消息过滤、会话隔离、重复扫描/重启去重，以及联系人变更时停止发送。远程桌面另做打开会话与输入框草稿检查，不用自动测试消息骚扰联系人。
