# 群聊发言概率配置设计

状态：已实现、验证并部署；按要求未重启，新增逻辑待下次正常启动加载。

## 目标与推荐语义

为各群提供独立的发言概率，将“灯 盏 堂”设为 `0.3`。建议概率作用于决策层已经决定发出的自然接话和闲时主动发言；不影响 @、点名、明确请求、私聊、活动和定时任务。`0.3` 表示符合参与条件的发言机会有 30% 获准发送，并非收到所有消息后随机回复 30%。

## 方案比较

1. 推荐：决策层判断后进行概率抽样，保留现有话题判断与直接响应。概率含义稳定，容易独立测试。
2. 判断前抽样：节省部分模型调用，但需要特别处理等待重判与直接响应，不采用。
3. 把概率写入模型提示：改动少，但无法保证数值对应的抽样行为，不采用。

## 配置与行为

新增根目录 `group-reply-settings.json`，采用默认概率和按群微信 ID 覆盖的结构。默认值 `1.0`，保留现有参与行为；范围为 `0` 到 `1`，拒绝布尔值、非有限数字和越界值。目标群按实际通讯录再次核对 ID；名称不参与匹配。

每个已判断的参与机会最多抽样一次。被概率拦下后记录为已处理，不因下一次轮询重复抽样。等待结果不抽样，最终决定发言时再抽样。消息阶段与后续闲时阶段是独立机会，各自最多抽样一次。`0` 停止自然插话，`1` 全部放行，仍受既有决策约束。@、点名、已核实的引用等既有直接响应路径绕过抽样；面向全群的公开问题仍属于自然参与。

配置文件支持运行时重读，合法更新原子生效；缺失时使用默认配置，损坏时保留最近有效配置并记录错误。首次安装新增逻辑需要进程正常重启才能加载；遵照已有要求，本次不重启机器人，不向运行中进程注入代码。

服务器参与层与本地代码不同，只对各自版本做最小补丁，保留服务器已有功能。

## 调参指南

根目录配置样例（群 ID 为示例，请替换为真实 ID）：

```json
{
  "default_probability": 1.0,
  "groups": {
    "11111111111@chatroom": 0.3,
    "22222222222@chatroom": 0.1
  }
}
```

- `default_probability` 控制未单独配置的群，缺省为 `1.0`。
- `groups` 中的值覆盖默认值，群名修改不影响配置。删除某群条目后恢复默认概率。
- 想减少自然插话可以调为 `0.1`；完全停止自然插话用 `0`；恢复原有决策行为用 `1`。概率不是模型的参与信心，也不保证每十条消息恰好回复三条。
- 保存合法 JSON 后，下一个需要抽样的参与机会自动读取。建议先写临时文件，再原子替换，避免编辑期间读取到半份文件。
- 错误 JSON、越界值、非数字、未知字段或超过 64K 字符的配置会记录 `group_reply_settings_error`，保留该实例最近一次有效配置；首次读取失败则使用默认值 `1.0`。删除文件同样恢复默认值。
- 被抽样拦下会记录 `group_reply_probability_skip`；决策结果落库为 `silent`，避免轮询重复尝试。
- 可选 `bot.json` 中 `selective_reply.probability_settings_file` 指定另一份配置；建议使用绝对路径，未指定时固定使用项目根目录文件。该路径设置需要启动时加载，文件内容支持自动重读。
- 源码仓库提供空的按群映射，实际微信群 ID 仅保留在服务器部署配置中。
