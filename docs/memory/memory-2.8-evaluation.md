## 改动与口径

语义模型仍须给出能逐字定位的原话来选择证据，但返回给回答阶段的是原候选上下文，包括限定、角色、时间、状态及原有来源引文，不再用摘录替换候选。原候选本身仍是有界窗口，不代表整段历史。推荐问题明确检索个人背景、经历和约束，不局限于现成建议。

从同一已授权候选池补充至多4条明确词面命中的记录，按相关性与来源互补排序；有效空选择也可补充。最终最多16条、选择器8800字符、回忆及自动上下文9000字符。没有额外模型调用。关闭语义读取、未绑定模型或非法模型响应仍保留有界词面路径；无模型路径6500字符。生产Bot总输入预算优先，超限仍降到必要画像。这轮增加读取预算，不能宣称同成本优化。

复用2.7的52个数据库副本，其中内容来自2.6全量重新写入。只更新版本标记，不重新提取、不复制旧回答或评分。使用冻结的deepseek-flash、温度0和原评分方法，生产10文件、评测脚本、数据和清单均有哈希与源代码快照。目录240条/160000字符、选择输出2400 token不变，未更换裁判或筛除错题。
