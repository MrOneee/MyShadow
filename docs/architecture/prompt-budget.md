# 人设与输入预算

三套人设正文（含工具使用习惯）各不超过3000字符，包含标点、英文和换行。人物背景卡、按会话注入的权限与记忆规则不属于正文；完整 system message 会比正文更长。token 使用现有中英文估算器估算，不是模型计费实数。

`Bot.input_budget_for` 从当前会话的 `context_token_budget` 扣除模型配置的 `max_tokens`、512 tokens 的消息封装/临时指令空间，以及当前可能提供的工具定义大小。通过好感门槛的任务指令计入任务工具，不计入本轮已禁用的表情工具；权限仍由实际消息发件人与当前会话关系核验。普通聊天的表情工具按可用上限预留，连续发送限制可能进一步减少实际工具。没有为尚未发生的两次历史查询预先扣除6000 tokens。

历史消息超过输入预算时仍按会话压缩旧记录与滚动摘要，再降级成员画像。当前请求与系统规则不做字符截断。若这些固定内容仍放不下，生成一次明确的失败回复并离开 pending 状态，避免重复尝试直至过期；这条路径不调用模型或任务管理工具。

这是首次请求装配预算。后续工具结果仍受现有工具条数/长度限制及所选运行时的上下文处理约束，并不取消整体限制，也不承诺任意长度的查询结果都能容纳。
