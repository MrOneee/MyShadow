## 分析

写入能力有所改善，但词面检索仍漏掉已经保存的答案。例如LoCoMo：

- 问“会哪些乐器”只回答clarinet，库中却另有明确“playing my violin”原话。类别词instrument与具体名violin没有词面重叠。
- 问理想舞蹈室遗漏Marley flooring，库中已保存对应原话和摘要。
- 问去过哪些州拒答，库中已有童年去Oregon公路旅行的原话。

新摘要中仍出现中文，虽有“保留原语言”提示，模型未稳定遵守；最终给回答模型展示的是逐字校验的原话，摘要只用于检索，不能据此直接断言事实错误。但中英文词面不一致进一步限制了召回。

来源重建诊断显示LoCoMo 118题中95题关联来源已保存、79题返回至少一个关联来源、59题返回全部关联来源；该诊断包括拒答题，而且LME按整会话来源匹配，均是偏乐观估计，不能当作官方Recall或精确错误比例。具体观察支持下一轮优先改进语义证据选择，而非继续无差别增加保存量。

部分题涉及宗教、政治等原有产品禁止保存的信息，不能为提升公开基准分数放宽过滤。仍有时间推理、列表完整性与拒答错误；增加原话不等于回答自动正确。
