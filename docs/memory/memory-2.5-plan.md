# 2.5.0目标迭代第三轮方案

先前2.4为LME24/36、LoCoMo51/92，未达标。主要观察：候选短截取损失具体细节；多种派生记录重复描述同一事件；回答把partial或画像冲突扩大为对全部原话的拒答，未完成证据支持的计数/比较。

本轮保持提取、数据、裁判、模型、最终6500字符及12条预算不变。只修改生产读取规则和语义选择目录：候选原文窗口120增至400字符，目录总量48000增至96000字符，仍最多240条。明确优先互补原话，避免同一来源的重复概括。增加读取规则的正向回答流程：先使用已有证据，允许去重计数、时间计算、直接蕴含；partial表示检索不完整，不意味着每个已返回事实无效。明确区分真正矛盾和不同事件，并保持真正缺失信息时拒答。不得编造个人经历、推断敏感属性或用常识填补缺失事实。

复制2.3库再做完整160题读取评测，以隔离写入波动。不试跑后择优，保留本轮所有结果；完成后才能决定下一轮。成本变化单列。验证现有权限、并发删除、停记、候选预算、来源角色和生产接线。达标后仍按目标协议做独立160题重复及封存34题确认，不以本轮单次过线代替完成。
