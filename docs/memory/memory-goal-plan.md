## 固定口径

采用既有160题回归集：LME可回答36题至少26题正确（72.22%），LoCoMo可回答92题至少56题正确（60.87%）。不把拒答题计入目标分母。旧2.2基线22/36、35/92。数据、裁判提示、deepseek-flash模型、temperature=0和thinking关闭保持不变，不注入标准答案、gold来源或测试题专用规则。不删除低分题，不重定义类别达标。

每轮冻结代码、方案与清单，完整报告该轮结果；失败运行保留。未达到目标就分析错误类型并安排下一轮，不择优隐藏版本。新的泛化验证34题在实现前抽样（种子20261025，排除先前194题），达到回归目标后运行，避免循环查看后把留出变成训练题。LoCoMo仍是原10个对话的新问题，必须披露不是新对话泛化。达到目标版本再对固定160题独立重复回答/评分检查稳定性，报告两次结果。

迭代筛查可只运行memory条件160题；none/oracle的既有结果只能标历史参考，不能冒充本轮重新运行。写入逻辑改变须在干净库重新写入完整历史；只读逻辑改变可复用明确标记的旧库副本，报告区别。正式验证保持同一模型与评分；若改变上下文/检索预算必须记录，不能归因于同预算算法提升。拒答表现、官方F1、用量、延迟、隐私回归同时报告。

不自动部署生产或提交Git。保留旧版快照、数据、源哈希、逐题回答/评分、每轮方案和报告、版本迁移/回退说明。现有未提交的独立功能修改不覆盖。

## 第一轮：2.3.0证据记录

补充完成标准（2.5确认结束后、2.6实现前）：2.5固定回归虽过线，新题LME8/12未达70%，目标继续。下一轮新增68题在实现前封存，固定160题两次过线后，新题可回答LME还须至少17/24、LoCoMo至少20/32。保留2.5新题失败结果，不读取其错题内容调参、不反复抽题择优。详见[2.6事前方案](memory-2.6-plan.md)。

分析：2.2相较2.1只在LME回归增加3题、LoCoMo增加1题，短画像仍丢失事件细节；needs_confirmation被过度用于历史问答，词面检索仍受概括与语种影响。证据充分时的数值/时间推理仍有损失。

方案：画像保留个性化职责，新增独立事件证据表。提取器从宿主已有事件中保留本人明确的非敏感事件/状态/偏好/计划原话片段，带来源ID、说出时间、类型和短摘要；摘要必须有连续原话支撑，不直接索引未筛选原始聊天，不从他人转述生成用户属性。已确认助手建议可以标明assistant角色，不能变为用户事实。

新增记录只在原会话、原成员内查询，不跟随画像共享；来源删除自动清理，停记不读写，忘记指定事实同时清理引用来源，证据专有条目也可指定删除。旧库升级只建空表和标记，不自动回扫聊天或复活被删除的资料；新消息及干净重放才得到新提取信息。短期源事件90天保留期到期后同步移除证据。

读取优先保留原话，和画像/确认经历共同检索，状态标记只约束对应画像，不能把原话描述的明确历史事件全部判成不可信。新增证据不声称已被现实验证。先保持6500字符预算和每轮两次主动回忆；必要预算变更另记下一轮方案。

本轮写入请求输出上限由6000提高到10000 token，以容纳全批至多24条证据；这是成本预算变化，需要单独报告。每条证据quote≤700字符、summary≤160字符，最终给回答模型只返回来源原话，不把未经逐字验证的summary当事实。新增英文敏感词防线作为模型筛选之外的补充，不放宽既有过滤。

No design pattern: plain implementation is simpler. 增加小型证据模块，保持现有事务与权限入口。先验证敏感过滤、引用角色、同源删除、指定删除、停记、到期清理、迁移幂等，再冻结运行。第一轮结果无论是否达标均记录，之后按证据决定下一轮。
