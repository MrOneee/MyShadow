# 图片读取工具

`read_image` 是现有微信图片解密与 DeepSeek 视觉识别链路上的 Agent 工具。普通图片仍会生成一次通用摘要；当摘要缺少问题所需的文字、表格、报错或局部细节时，Agent 可以指定图片编号和问题重新读取。

工具候选完全由宿主程序绑定，模型不能传入群ID、联系人、文件路径、URL或消息ID。可读取范围只有：

- 当前消息本身的图片；
- 当前消息在同一会话中明确引用的图片；
- 当前提问者在提问前两分钟内发送的最近三张图片。

多张图片按从旧到新编号1到3。没有编号且仅有一张时默认读取；存在多张时先返回数量，让Agent指定编号。单轮最多执行三次不同的读取；相同编号和问题返回本轮缓存结果。

本机图片仍经过原有安全链路：只在账号附件目录寻找数据库给出的哈希文件，限制12 MiB和2500万像素，完成V1/V2解密后清除元数据并缩放到1600×1600以内。工具不会下载消息XML中的远端地址。

视觉请求使用 `ai.json` 中的 `vision_model`，当前配置为 `deepseek-v4-flash-vision-exp`。通用摘要可以落入按会话和消息定位的缓存；带特定问题的结果不覆盖通用摘要，避免后来把一次局部回答误当整张图的说明。
