# DSH 执行层

接入官方 [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)，固定 `dsh-v0.1.2-rc.1` / `a66e4702047846cdaa10c66c9d3df3951f5ea70d`，Python SDK 与自带运行时均为 `0.1.2rc1`。这是预发布版本，升级时应重新运行集成测试；不跟随 master 自动升级，也不修改上游执行循环。

## 边界

| 层 | 职责 |
|---|---|
| 微信宿主 | 轮询、按群排队、可信发送者与权限、历史投影、实际发送及回执、定时任务、活动状态与恢复 |
| DSH | 模型与工具循环、工具 schema、网络重试、搜索和网页读取、会话日志、长任务上下文压缩 |
| `agent_runtime` Adapter | 按群绑定、工具桥接、预算、结构化提交验证、有限纠正、效果幂等账本、诊断 |
| Skill | 领域规则和代码。海龟汤的署名证据、题面/汤底核对、质量审核、提示、进度和揭晓仍在 Skill 中 |

`HarnessAI` 接管聊天、决策、摘要与活动推理。已在工具回调内部的短推理（例如独立质量审核、搜索词提炼）直接调用原模型客户端，不再嵌套启动 DSH；其 schema 校验/有限重试仍由宿主负责，失败反馈给外层 Agent 修正。搜索使用 DSH 原生 `web_search` / `web_fetch`，保留候选来源、查询和读取结果。天气、表情、历史和管理员定时工具通过已授权的宿主闭包注册，不允许模型选择任意群或发送者。裸 Shell、编辑器没有注册给模型。

Skill 的有状态执行仍走 Registry/Host；不是让 DSH 自行运行磁盘上的任意脚本。`Context.research()` 是通用的有证据工具循环，接收任务指令、结果 schema 和验证器；没有海龟汤专用判断。

## 会话、恢复与资源

宿主持有群聊历史和活动状态。每个群有独立 DSH home/workspace；每次推理创建任务会话，避免把不同裁判角色的私密信息混入长期聊天。正常对话只注入宿主预算内的历史。长检索使用原生 token meter/compaction（65% 压力触发，保留 12000 tokens 尾部）。

默认每次 12 步、16 次工具、240 秒；研究任务最多 18 步、600 秒，工具额度仍受配置限制。最后三步保留给收尾，提交工具不消耗外部工具额度。结构化任务只接受成功的 `submit_result`；普通文字不能充当结果，缺提交时最多继续同一 DSH 会话两次，仍受总步数和时间限制。

崩溃后由现有 inbox/outbox 恢复业务工作；已完成的相同任务可复用结果，未完成任务新建尝试，保留旧轨迹和效果账本。**当前不自动续接被中断的模型 token 流**。表情和定时变更执行前先记账，结果不确定时不重发；微信发送层仍以实际回执为准。

工具在调用方线程执行，避免跨线程使用 SQLite 或桌面租约。每次任务结束关闭 DSH 进程；SDK 0.1.2rc1 的读管道关闭兼容处理集中在 Adapter 中。当前 2 GiB 容器内通过进程内准入锁限制一个活动 DSH 实例；群 worker 仍为 2，消息与权限分别隔离，但长检索会让其他群的 AI 调用等待。上游 SDK 在单次运行中仍会收集事件，因此长任务内存并非零；扩充容器预算并测量峰值后再提高运行时并发。

## 配置与诊断

安装 `requirements.txt`（Python >= 3.10，SDK 自带运行时），设置 `bot.json.harness.enabled=true`。沿用现有 `ai.json` 中的 DeepSeek key/base_url，无额外搜索 API key。原有 Docker 构建会安装新依赖。

`python -m agent_runtime --group '<群ID>'` 列出最近执行状态、用量及日志目录，不打印私密对话和汤底。`harness-data/groups/<hash>/runs/<run>/` 保存请求、校验和工具事件、网页结果、结果或失败详情；上游完整日志在该群的 `home/sessions`。这些是私密运行数据，不应提交到 Git 或作为群消息发送；目前不自动删除日志，运维需按磁盘保留策略归档。

回滚：关闭服务、恢复部署备份的代码与 `bot.json`，再启动；也可临时设置 `harness.enabled=false` 使用保留的旧路径。不要回滚微信登录状态或覆盖当前活动数据库。

## 验证

`python -m unittest discover -s tests -t . -p 'test_*.py'` 包括宿主回归、工具桥接的故障注入，以及真实 DSH 对本地确定性模型接口的集成测试；不需要模型 API key。真实联网场景应另外在隔离的 preview Host 中验收，严禁把测试汤底发到群里。
